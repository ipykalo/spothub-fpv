# Security

SpotHub FPV runs at https://spothubfpv.com and is looked after by one person.
If you find a security problem in the site or in this code, thank you — please
tell me privately rather than in a public issue.

## Reporting

- **Preferred:** GitHub's private reporting — the **Security** tab of this
  repository, then **Report a vulnerability**.
- **Or by email:** privacy@spothubfpv.com.

Say what you found, how to reproduce it, and what it lets someone do. You will
get an answer within a few days, and word when it is fixed. Please give it a
reasonable time to be fixed before telling anyone else.

## In scope

The site at spothubfpv.com and its API, and the code in this repository —
especially anything that lets one pilot read or change another pilot's data,
sign in as someone else, or get past a private build, spot or draft.

## Please do not

- access, change or delete data that is not yours, beyond the least needed to
  show the problem;
- run load tests, scanners or anything that could slow the site for the
  pilots using it;
- try to trick the people who use it.

There is no bug bounty: this is a hobby project with no budget. A fixed
problem gets a thank-you in the fix's notes, if you would like one.
